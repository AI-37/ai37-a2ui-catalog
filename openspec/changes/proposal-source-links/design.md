# Design: ссылки источника ProposalCard

## Решения

1. **Список рядом с `href`, а не вместо него.** `href` — ссылка на всю подпись, им уже пользуются
   источники пунктов из документов. `links` — отдельные объекты после подписи. Заменить `href` списком
   значило бы сломать эмитентов 0.44.0.
2. **Ссылка без адреса — подпись.** Право открыть запись есть у OWNER/EDITOR, адрес считает агент (S6).
   Рендер ролей не знает: нет `href` — нет перехода. Удалённая запись приходит так же, подписью
   «… — запись удалена».
3. **Пустой список равен отсутствию поля.** Агенту не нужно выкидывать ключ, когда записей нет. Одних
   ссылок для источника мало, нужна подпись или цитата: иначе непонятно, что это за ссылки.
4. **Место.** У пачки — в подписи под цитатой, в одной строке с ней, с переносом. У пункта — в той же
   приглушённой строке после цитаты. Каждая ссылка в своём `span`, чтобы подписи без адреса не
   слились в один текст.
5. **До 20 ссылок.** Голосовых в одной пачке единицы; потолок — от разрастания карточки, как `files` у
   `ArtifactCard`.

## Тема

Своих цветов нет: ступени набора и `a2ui-t--accent` для ссылки.
