## ADDED Requirements

### Requirement: Кнопка прохода переводит фокус в раскрытую секцию

Пока у подписи прохода (`nextLabel` / `pendingLabel`) есть следующая цель,
нажатие кнопки подвала ДОЛЖНО (SHALL) раскрыть эту цель И перевести фокус
внутрь неё: на первый фокусируемый контрол секции, а при его отсутствии — на
заголовок секции.

Фокус ДОЛЖЕН (SHALL) переводиться после того, как панель раскрыта: `focus()`
по скрытой панели браузер выполняет без результата.

Фокус ОСТАВАТЬСЯ НА КНОПКЕ ПОСЛЕ ПЕРЕХОДА НЕ ДОЛЖЕН (SHALL NOT) — иначе проход
ведёт глазами и не ведёт руками.

#### Scenario: Проход по секциям с клавиатуры

- **WHEN** пользователь нажимает кнопку прохода, и следующая цель существует
- **THEN** её секция раскрыта
- **AND** фокус стоит на первом фокусируемом контроле этой секции
- **AND** значение можно вводить, не касаясь мыши

#### Scenario: Секция без контролов

- **WHEN** раскрытая цель не содержит фокусируемых контролов
- **THEN** фокус стоит на заголовке этой секции

### Requirement: Отправка фокус не двигает

Когда целей прохода не осталось и кнопка отправляет документ, фокус
ПЕРЕНОСИТЬСЯ НЕ ДОЛЖЕН (SHALL NOT): следующее действие — сама кнопка.

#### Scenario: Последний шаг

- **WHEN** подпись кнопки сменилась на подпись отправки
- **THEN** фокус остаётся на кнопке

### Requirement: Раскрытие мышью фокус не трогает

Раскрытие секции кликом по её заголовку фокус ПЕРЕНОСИТЬ НЕ ДОЛЖНО (SHALL NOT).
Каретка переезжает только по кнопке прохода.

#### Scenario: Секция раскрыта вручную во время ввода

- **WHEN** пользователь печатает в поле и кликом раскрывает соседнюю секцию
- **THEN** каретка остаётся в поле, где шёл ввод
