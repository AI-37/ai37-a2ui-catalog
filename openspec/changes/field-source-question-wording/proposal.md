## Why

Метка `question` подписывает поле словами «из вопроса»
(`primitives/field-source-label.ts:22`). На живой форме КЕО
(`spai-daylight-factor-calc-agent`) это читается неверно: значение попало в
поле потому, что агент **разобрал первое сообщение пользователя**, а не
потому, что пользователь ответил на заданный агентом вопрос. Пользователь
вопроса не видел — видит подпись «из вопроса» и не понимает, о каком вопросе
речь.

Агент-источник тут ни при чём: он отдаёт только код словаря
(`toCalcFieldSourceKind`: `UserInput → 'question'`), формулировка целиком
принадлежит каталогу.

Попутно вскрылось расхождение двух словарей одного и того же вида источника:

| файл | `question` |
| --- | --- |
| `primitives/field-source-label.ts` | «из вопроса» |
| `renderers/calc-field-source-label.ts` | «из вашего вопроса» |

Расчётные редакторы (КЕО) при этом рендерят ПЕРВЫЙ — то есть отдельный
«расчётный» словарь до этой подписи не доходит.

## What Changes

- **Переформулировать `question`** в обоих словарях на текст, который не
  ссылается на несуществующий вопрос. Кандидаты: «разобрано», «из вашего
  описания», «из вашего сообщения». Выбор — за владельцем UX-текстов.
- **Свести расхождение**: либо один текст в обоих словарях, либо явное
  объяснение в комментарии, почему расчётные редакторы говорят иначе.
  Сейчас различие выглядит непреднамеренным.
- **Проверить, какой словарь реально доходит до расчётных редакторов** —
  скриншот КЕО показывает «из вопроса», хотя существует
  `calc-field-source-label.ts` с другим текстом.
- Схемы props НЕ меняются: код `question` остаётся, правится только слово.

## Impact

- Затрагивает все редакторы на общем словаре: `ConstructionsEditor`,
  `LiftEditor`, расчётные (КЕО, инсоляция).
- Тесты со строкой «из вопроса»: `tests/react/lift-editor.test.tsx`,
  `tests/react/constructions-editor.test.tsx`.
- Агенты не трогаются — они шлют код, не текст.

## Open question

Точная формулировка не выбрана. `question` покрывает ДВА случая сразу:
разбор свободного сообщения пользователя и его submit формы. Слово должно
подходить обоим — «разобрано» хорошо для первого и странно для второго.
