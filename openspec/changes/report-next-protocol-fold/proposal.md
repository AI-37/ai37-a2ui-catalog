## Why

Подробный расчёт нельзя проверить, не скачав файл. Строка «Протокол расчёта» в отчётах `*Next` не
раскрывается, а `protocol.content` не выводится на экран вовсе — это решение 15 change'а
`reports-next`. Продуктовое требование (план `docs/plans/lift-report-protocol-fold.md`,
идея в Notion): пользователь должен раскрыть блок прямо в чате, увидеть промежуточные вычисления,
при необходимости поправить исходные данные и пересчитать; скачивание остаётся дополнительной
опцией.

Мотив решения 15 — «вердикт первым экраном» — сохраняется: блок свёрнут по умолчанию, как фолды
«Исходные данные» и «Допущения» (change `next-report-folds`).

## What Changes

- Примитив `ReportProtocolCard` с `children` становится раскрывашкой: `Collapsible`, свёрнута по
  умолчанию, панель `keepMounted`. Без `children` — прежняя строка без шеврона.
- Новый примитив `ReportMarkdown` (+ `ReportMarkdownTable`): `protocol.content` рендерится как
  markdown — разделы, списки, GFM-таблицы, формулы `$…$` / `$$…$$` через KaTeX. Сырой HTML не
  рендерится. Таблица — в своём контейнере со скроллом.
- Общий рендерер `ReportNextProtocolCard` отдаёт панель всем трём отчётам: `LiftReportNext`,
  `ThermalReportNext`, `KeoReportNext`.
- Мета и «Скачать ⌄» — снаружи триггера: внутри они попали бы в доступное имя кнопки, а клик по
  меню форматов переключал бы раскрытие.

## Capabilities

### Modified Capabilities

- `reports-next`: решение 15 («`protocol.content` не выводится, участвует только в скачивании»)
  отменяется — содержимое выводится под свёрнутым по умолчанию катом. Остальные решения change'а
  (слова статусов от рендерера, акцентная рамка рекомендованного, один вид триггера скачивания) в
  силе.

## Impact

- Схемы props НЕ меняются: JSON Schema компонентов та же, Python-зеркало не тронуто; в `public/`
  правятся только три строки `description`. Поле `content` описано как markdown — обычный текст
  остаётся валидным markdown, прежние наполнения работают.
- Новые зависимости `catalog-react`: `react-markdown`, `remark-gfm`, `remark-math`,
  `rehype-katex` (версии совпадают с теми, что уже стоят в spai-ui — дублей в бандле потребителя
  не появляется).
- Шрифты KaTeX подключает хост (`katex/dist/katex.min.css`) — тот же контракт, что у
  `LatexFormula`.
- Старые рендереры (`LiftReport`, `ThermalReport`, `KeoReport`) печатают `content` дословно в
  `<pre>` — markdown виден там исходником. Остаются для прежних клиентов.
