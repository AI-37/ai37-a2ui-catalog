## ADDED Requirements

### Requirement: Шапка карточки — чтение с явным редактированием

Блок шапки раскрытой карточки (тип конструкции, разновидность, название)
SHALL по умолчанию отображаться в режиме чтения — текстом, без контролов —
с кнопкой «Изменить». Клик SHALL открывать форму шапки: селект типа, селект
разновидности (для типа с разновидностями), инпут названия и кнопки
«Сохранить» / «Отмена». Форма SHALL редактировать локальную копию полей:
до «Сохранить» заголовок карточки, live-Rпр и состояние редактора SHALL NOT
изменяться. «Сохранить» SHALL записать копию в состояние редактора и закрыть
форму; «Сохранить» без изменений и «Отмена» SHALL закрыть форму, не меняя
состояния и не порождая action'ов.

#### Scenario: Шапка по умолчанию — текст

- **WHEN** пользователь раскрывает карточку
- **THEN** тип и название показаны текстом, селектов и инпута шапки нет
- **AND** видна кнопка «Изменить»

#### Scenario: Ввод в форме не меняет карточку

- **WHEN** пользователь открывает форму шапки и меняет название, не нажимая
  «Сохранить»
- **THEN** заголовок карточки показывает прежнее название

#### Scenario: Сохранить обновляет шапку

- **WHEN** пользователь меняет название и нажимает «Сохранить»
- **THEN** форма закрывается, заголовок и режим чтения показывают новое
  название

#### Scenario: Смена типа фиксируется по коммиту

- **WHEN** пользователь меняет тип на «без слоёв» и нажимает «Сохранить»
- **THEN** карточка перерисовывается под новый тип (паспортное Rпр вместо
  слоёв) только после коммита

### Requirement: Паспортное Rпр — чтение с явным редактированием

Для типов без слоёв значение `rprPassport` SHALL отображаться в режиме
чтения текстом (незаполненное — предупреждением в духе подсветки
невалидности) с кнопкой «Изменить»; форма SHALL содержать числовой инпут и
кнопки «Применить» / «Отмена» с той же семантикой коммита, что у формы
шапки.

#### Scenario: Применить обновляет значение и live-Rпр

- **WHEN** пользователь открывает форму паспортного Rпр, вводит значение и
  нажимает «Применить»
- **THEN** режим чтения показывает новое значение
- **AND** чип Rпр карточки пересчитан

#### Scenario: Отмена не оставляет следа

- **WHEN** пользователь правит значение в форме и нажимает «Отмена»
- **THEN** показано прежнее значение, состояние редактора не изменилось

### Requirement: Одна форма на весь редактор — любого вида

Формы слоя, шапки и паспортного Rпр SHALL делить одно место единственной
раскрытой формы редактора: открытие любой из них SHALL закрывать текущую
раскрытую форму любого вида с отбросом её незакоммиченных правок.

#### Scenario: Форма шапки закрывает форму слоя

- **WHEN** открыта форма слоя с правками и пользователь нажимает «Изменить»
  у шапки другой (или той же) карточки
- **THEN** форма слоя закрыта, его правки отброшены, открыта форма шапки
