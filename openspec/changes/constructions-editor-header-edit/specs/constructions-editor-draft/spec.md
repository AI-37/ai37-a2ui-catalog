## MODIFIED Requirements

### Requirement: Автосохранение на структурных правках

При заданном `draftAction` компонент SHALL отправлять
`dispatchAction({event: {name: draftAction, context: {…}}})` после каждого
**коммита** состояния конструкций: добавления конструкции, удаления
конструкции, коммита формы слоя («Добавить», «Удалить слой», «Применить» с
изменёнными полями), коммита формы шапки «Сохранить» с изменёнными полями и
коммита формы паспортного Rпр «Применить» с изменённым значением. Коммит без
изменений SHALL NOT порождать action. Контекст SHALL содержать полный текущий
массив `constructions` (при наличии `general` — и его) в том же формате, в
каком он уходит в `submitAction`, включая незаполненные и невалидные записи.
Определение коммита SHALL быть явным событием, а не выводиться из сравнения
состояний.

#### Scenario: Добавлена конструкция

- **WHEN** пользователь нажимает кнопку добавления конструкции
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` присутствует новая пустая конструкция
  вместе со всеми ранее введёнными

#### Scenario: Сохранена шапка с изменёнными полями

- **WHEN** пользователь меняет название в форме шапки и нажимает «Сохранить»
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` конструкция содержит новое название

#### Scenario: Применено паспортное Rпр

- **WHEN** пользователь вводит значение в форме паспортного Rпр и нажимает
  «Применить»
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` конструкция содержит введённое
  `rprPassport`

#### Scenario: Коммит без изменений

- **WHEN** пользователь открывает форму шапки и сразу нажимает «Сохранить»
- **THEN** компонент не отправляет ни одного action'а

#### Scenario: Применить слой с изменёнными полями

- **WHEN** пользователь вписывает λ в форме слоя и нажимает «Применить»
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` слой содержит введённую λ

### Requirement: Правки полей не запускают автосохранение

Компонент SHALL NOT отправлять `draftAction` в ответ на ввод внутри ещё не
закоммиченной формы (слоя, шапки, паспортного Rпр), на «Отмену» любой формы,
на переключение раскрытой формы, на правку полей вкладки общих данных и на
разворачивание/сворачивание карточек. Такие правки SHALL уезжать наружу
вместе со следующим коммитом либо с `submitAction`.

#### Scenario: Ввод в форме шапки без коммита

- **WHEN** пользователь печатает в инпуте названия открытой формы шапки, не
  нажимая «Сохранить»
- **THEN** компонент не отправляет ни одного action'а

#### Scenario: Правка общих данных перед коммитом

- **WHEN** пользователь меняет tв на вкладке общих данных, а затем коммитит
  форму слоя с изменённой толщиной
- **THEN** отправляется ровно один action `draftAction`
- **AND** в `context.general` присутствует новое tв
