## ADDED Requirements

### Requirement: Контракт `generalSources`

Схема SHALL принимать опциональный проп `generalSources` — запись «ключ поля
`general` → описание источника». Описание SHALL содержать `source` — одно из
`project`, `question`, `suggested`, `default` — и MAY содержать `note`
(человеческое обоснование одной строкой, до 200 символов). Ключи, которых нет
в `general`, SHALL отвергаться схемой.

#### Scenario: Валидный блок источников

- **WHEN** агент прислал `generalSources: {tv: {source: 'suggested', note:
  'норма для жилых по ГОСТ 30494'}}`
- **THEN** props проходят валидацию схемы

#### Scenario: Неизвестный ключ

- **WHEN** агент прислал `generalSources` с ключом, которого нет в `general`
- **THEN** валидация схемы отвергает props

#### Scenario: Без блока источников

- **WHEN** `generalSources` не задан
- **THEN** компонент рисует поля без подписей источника и без акцентов

### Requirement: Отрисовка по источнику

Поле с описанным источником SHALL получать подпись под контролом и визуальный
маркер, различающий источники: `project` — приглушённый контрол и подпись «из
проекта»; `question` и `suggested` — акцентная рамка контрола; `default` —
маркер «принято по умолчанию». При заданной `note` подпись SHALL содержать её
текст; без `note` SHALL показываться только название источника.

#### Scenario: Предложенное агентом значение

- **WHEN** у поля `tv` источник `suggested` с `note` «норма для жилых по
  ГОСТ 30494»
- **THEN** контрол tв имеет акцентную рамку
- **AND** под ним видна подпись с этим текстом

#### Scenario: Значение из проекта

- **WHEN** у поля `city` источник `project`
- **THEN** под полем видна подпись «из проекта»

#### Scenario: Источник без обоснования

- **WHEN** у поля источник `question` без `note`
- **THEN** подпись показывает только название источника, без пустого хвоста

### Requirement: Источник ничего не блокирует

Ни одно значение `source` SHALL NOT делать поле недоступным для ввода:
provenance — оформление и подпись, а не блокировка. Компонент нигде не
блокирует пользователя.

#### Scenario: Правка поля из проекта возможна

- **WHEN** у поля `city` `source: 'project'`
- **AND** пользователь вводит другой город
- **THEN** значение меняется
- **AND** submit уходит с новым значением

### Requirement: Правка снимает provenance-оформление

После того как пользователь изменил значение поля, компонент SHALL перестать
показывать для него подпись источника и акцентный маркер: значение стало
пользовательским. Возврат к исходному значению SHALL NOT возвращать
оформление в рамках текущего хода.

#### Scenario: Подпись исчезает после правки

- **WHEN** у поля `tv` источник `suggested` и пользователь меняет его значение
- **THEN** подпись «предложено — …» и акцентная рамка у поля пропадают

#### Scenario: Соседние поля не затронуты

- **WHEN** пользователь правит только `tv`
- **THEN** подписи источников у `city`, `buildingType` и `condition` остаются

### Requirement: Provenance не уходит наружу

`generalSources` SHALL NOT включаться в payload `submitAction` и
`draftAction`, и правка поля SHALL NOT порождать отдельный action. Payload
SHALL остаться `{general, constructions}`.

#### Scenario: Payload без источников

- **WHEN** пользователь нажимает submit на props с `generalSources`
- **THEN** payload содержит только `general` и `constructions`
