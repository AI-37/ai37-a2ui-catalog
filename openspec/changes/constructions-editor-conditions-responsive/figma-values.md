## Геометрия

- Карточка: радиус **14**, заливка `#fafaf9`, граница `#e5e4e1` 1px.
- Шапка: высота 40, паддинги `13 20`, заливка `#f1f1ef`, нижняя граница.
- Body: паддинги `18 20`, вертикальный gap между группами **20**.
- Группа (заголовок секции + содержимое): col, gap **10**.
- Ряд полей: row, gap **14**; поле — col, gap **6**.
- Контрол: высота **37**, паддинги `10 12`, радиус **9**.
- Кнопки: радиус **9**; вторичная — паддинги `8–9 / 13–14`, граница
  `#e5e4e1`; submit — заливка `#1f1f1e`, паддинги `10 20`, высота 34.
- Свёрнутый блок (баннер, «Коэффициенты»): радиус **10**, паддинги `11 14`,
  заливка `#f1f1ef`.

## Оформление по источнику

| Источник | Контрол | Caption |
|---|---|---|
| `project` | заливка `#f1f1ef`, граница `#e5e4e1` 1px; значение `#1f1f1e` | `#6e6e6a` + иконка-папка 12×12 |
| `suggested` / `question` | заливка `#fafaf9`, граница **`#245a87` 1.5px**; значение `#6e6e6a` | `#245a87` |
| `default` | свёрнутый блок `#f1f1ef` с точкой-маркером | `#6e6e6a` |

Замеченное расхождение с текущей спекой: у поля `project` рамка **есть**
(`#e5e4e1` 1px), от обычного контрола его отличает заливка `#f1f1ef` и
отсутствие акцента. Требование «заливка без видимой рамки» нужно поправить.

Значение предложенного поля набрано приглушённым цветом (`#6e6e6a`), а не
основным — это визуальный сигнал «ещё не подтверждено».

## Ширины и брейкпоинт

- Читающая колонка чата на десктопе — **720**; карточка занимает её целиком.
- Поле в ряду — **333** при контейнере 680 (два поля + gap 14).
- Мобильная читающая колонка (Mobile 390) — **358**.

Порог 560 из `design.md` разделяет эти два случая корректно: 720 → две
колонки, 358 → одна. Отдельного мобильного макета брифа теплотехники в файле
нет — узкую раскладку выводим из общей мобильной сетки (390 − 2×16).
