# Proposal: AttachmentChoiceCard — необязательный `skip`

## Why

Агент thermal-calc на ходе «проверь теплотехнический расчёт» без файла отвечает только текстом «приложите
файл и повторите запрос» (план AI-37/docs#522). Ему нужна та же карточка загрузки, что у Минстроя, но без
кнопки «продолжить без файла»: у проверки расчёта нет пути без документа.

Ревью плана (#522) отклонило отдельный `FileUploadCard`: карточка «только загрузка» — это
`AttachmentChoiceCard` без ветки skip. Совпадают загрузка, ручка, хук, 4 состояния файла и payload attach;
разница — одна кнопка. Все подписи (7 штук: `title`, `description`, `pickLabel`, `hint`, `attach.label`,
`skip.label`, `accept`) уже приходят пропсами; зашиты в рендерере только 4 общие строки («Файл»,
«Загружаю …», «Не удалось загрузить файл…», «Убрать …»), годные для любого файла.

## What Changes

- Схема: `skip` → `.optional()` (Zod, JSON Schema в `public/`, Python-зеркало `skip = None`).
- `description` определения: когда опускать `skip`.
- Рендерер: без `skip` кнопка «без файла» не рендерится — ветка вынесена в
  `attachment-choice-card-skip-button.tsx` с ранним `return null`. Attach-кнопка, disabled-логика и payload
  не менялись.
- Фикстура `fixtures/valid/attachment-choice-card-attach-only.json` (тексты теплотеха), превью в demo.
- Версия пакетов 0.41.0 → 0.42.0.

## Impact

- Неломающее ослабление контракта: прежние payload со `skip` валидны, `CATALOG_VERSION` не меняется.
- Единственный эмитент сегодня — Минстрой (подпись), всегда шлёт `skip`; его рендер не меняется,
  существующие тесты проходят без правок.
- Потребители: `spai-ui` (рендерит), `spai-thermal-calc-agent` (схемы; начнёт слать карточку без `skip`).
