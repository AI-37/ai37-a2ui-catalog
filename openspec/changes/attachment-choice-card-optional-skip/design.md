# Design: AttachmentChoiceCard — необязательный `skip`

## Решения

1. **Ослабить схему существующего компонента, а не заводить новый** — решение ревью плана AI-37/docs#522
   (2026-10-16), принято владельцем. Цена: имя `AttachmentChoiceCard` для варианта без выбора читается
   неточно; компенсируется `description` определения, по которому агент выбирает компонент.
2. **Нет `skip` — нет кнопки**, а не неактивная кнопка: у такого хода нет пути без файла, показывать его
   незачем.
3. **Подвал с одной кнопкой — без отдельной раскладки.** `footerStyle` (flex, gap, wrap) с одним ребёнком
   даёт главную кнопку слева, как у `ConstructionsNextFooter` без вторичной.
4. **Тексты карточки теплотеха — пропсы агента**, в каталоге только фикстура с черновыми текстами.
   Владелец посмотрел SSR-превью всех состояний (2026-10-22) и принял вид («кайф») — это гейт макета
   (этап 3) в облегчённом виде: меняется одно состояние существующей карточки, `/proba`-страница не нужна.

## Вне охвата

- Тёмная тема `*Next`-набора — change `next-dark-theme`, не здесь.
