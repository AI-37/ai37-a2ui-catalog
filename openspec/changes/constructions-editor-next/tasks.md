## Что осталось владельцу дизайна

Блок 0 не закрыт: три вопроса из `design.md` меняют вид существующих экранов и
решаются не реализацией. Пока они открыты, новый рендерер взял метрики CE, как и
предписано в `design.md`:

- ступень `sub` — 12px (значение пакета), не 11px из песочницы;
- начертание титулов — 500 (`--a2ui-text-weight-strong`), как у CE и отчётов;
- главный submit — метрики CE: 10/20, r9, без жирности.

Решение владельца меняет одну строку в `packages/catalog-react/src/primitives/kit-tokens.ts`
(и `button-css.ts` для submit), рендерер трогать не придётся.
