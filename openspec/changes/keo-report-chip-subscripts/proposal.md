# Чипы «Исходных данных» отчёта КЕО рендерят подстрочные индексы

## Why

Карточка «Исходные данные» `KeoReportNext` печатает подписи чипов и note
группы как есть (`keo-report-inputs.tsx:34,42`). Агент сегодня шлёт туда
литеральный LaTeX — на экране «$d_п$ · $b_п$ · $h$, м», «$\rho_ф$»,
«$\varepsilon_б$» долларами и макросами (инбокс агента КЕО, b-20).

KaTeX в каталоге есть только у отдельного компонента `LatexFormula`; подписи
чипов через него не проходят и проходить не должны — контракт подписей
каталога плоский: `d_п`, `ρ_ф` (см. `label-subscripts`). Агент чистит свои
строки своим change'ем (`keo-report-label-notation`); этот change учит
карточку рендерить плоскую нотацию индексами — тем же правилом, что подписи
полей формы.

## What Changes

- **Подписи чипов** (`chip.label`) прогоняются через `renderLabelSubscripts`.
- **Заголовок группы** (`group.label`) и **note группы** (`group.note`) — тем
  же хелпером: в note агент называет `ε_б` и `ε_зд`.
- Значения чипов (`chip.value`) не трогаются — там числа и текст без индексов.

## Capabilities

### Modified Capabilities

- `label-subscripts` — добавляется поверхность: чипы, заголовки групп и note
  карточки «Исходные данные» отчёта КЕО.

## Impact

- `packages/catalog-react/src/renderers/keo-report-inputs.tsx` — три места
  рендера строк.
- Тесты `keo-report-next`: чип `d_п · b_п · h, м` с подстрочными индексами.

## Зависимости

- Хелпер приезжает change'ем `next-label-subscripts` — этот идёт следом.
- Пока агент шлёт `$...$`, хелпер долларов не трогает (правило узкое) —
  порядок мержа с агентским `keo-report-label-notation` свободный, экран
  доводится до правильного только парой.

## Non-goals

- Рендер LaTeX в чипах — не делаем, контракт плоский.
- Markdown-протокол в тексте хода — рендерит чат хоста, не каталог.
- Состав чипов и предупреждающая note про подстановку ε (b-22 агента) — здесь
  только нотация.
