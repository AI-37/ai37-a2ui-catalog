## ADDED Requirements

### Requirement: Чипы исходных данных отчёта рендерят индексы подстрочными

Подписи чипов, заголовки и note групп «Исходных данных» ДОЛЖНЫ (SHALL)
рендериться по правилу подстрочных индексов `label-subscripts`:
`d_п · b_п · h, м` показывается базами с подстрочными индексами, без `_`
на экране.

Значения чипов (`chip.value`) обрабатываться НЕ ДОЛЖНЫ (SHALL NOT).

#### Scenario: Чип с индексами

- **WHEN** отчёт приходит с чипом `label: 'd_п · b_п · h, м'`
- **THEN** подпись показана как «d<sub>п</sub> · b<sub>п</sub> · h, м»

#### Scenario: Note группы коэффициентов

- **WHEN** группа приходит с note, называющей `ε_б` и `ε_зд`
- **THEN** индексы «б» и «зд» показаны подстрочными

#### Scenario: Чип без индексов

- **WHEN** отчёт приходит с чипом `label: 'Ориентация'`
- **THEN** подпись показана без изменений
