# Design: AttachmentChoiceCard

## Решения

1. **Две кнопки без radio** — решение владельца (Сергей, 2026-10-12, Telegram). Выбор и есть отправка;
   «Продолжить» с невыбранным пунктом исчезает как класс ошибки. Цена: нет «подтвердить выбор» — клик
   необратим, как у кнопок отчётов.
2. **Кнопка `attach` блокируется до загрузки** — отход от канона редакторов «без клиентской блокировки».
   Причина: без `fileId` агенту нечего принять, «пометка вместо блока» здесь означала бы пустой submit.
   Решение владельца.
3. **Загрузка сразу при выборе, а не по клику `attach`** — как у «+» композера; клик отправляет уже готовый
   `fileId`, ошибка видна до отправки.
4. **Ручка — константа `CHAT_ATTACHMENTS_ROUTE`, а не проп.** Адрес ручки — свойство хоста, агент его не
   знает (прецедент `AGENT_RESOURCE_ROUTE`). `contextId` — проп: тред знает агент.
5. **Без retry на 401.** Канон `use-lookup-suggest.ts`: каталог не владеет авторизацией хоста. Сбой —
   состояние `error` с текстом и повторным выбором.
6. **Файл в накопитель `context_refs` хоста не пишется.** На action-ходе chat-backend строит
   `context_files` по полке треда, файл там уже есть; агент берёт его по явному `fileId`.
7. **После отправки обе кнопки гаснут** (`sent`), на прошлой поверхности карточка под `withReadOnlyGate`.
8. **Этап демо-макета пропущен:** визуальный источник — HTML-макет, принятый вместе с планом
   (https://claude.ai/artifact/RPi8gFsyznUqJMUPdCS33G). Гейт глазами — сразу на стенде (этап 6).

9. **Вёрстка — по канону `*Next`, а не своя** (замечание владельца на стенде, 2026-10-12: первая версия
   «отсебятина»). Сверено с `KeoNextScreen`, `ConstructionsNextFooter`, `/proba/system`:
   - шапка — утопленная полоса `Card flat` + `CardHeader`, как у КЕО и лифтов, а не голый `<h3>`;
   - подвал — один ряд: вторичная `Button size="lg"` рядом с главной `variant="filled" size="lg"` **без
     тона** (у КЕО и теплотеха главная кнопка без `tone="accent"`); в первой версии кнопки стояли в две
     строки разного размера, а главная была accent;
   - выбор файла — обычная `Button`: пунктир в наборе только у «+ Добавить …»;
   - выбранный файл — `DataChip` («Файл · имя · размер»), снять — icon-only `Button size="sm"`.
   Скриншоты: `preview/{idle,ready}-{720,360}-{light,dark}.png` — две ширины контейнера, обе темы.

10. **Структура — один компонент на файл, ветки ранним `return null`** (сверка со скиллом
   `a2ui-component`, 4.4): слот файла разнесён на `*-file-picker`, `*-file-uploading`, `*-file-chip`,
   строки — `*-note` и `*-error`, все интерфейсы — в `attachment-choice-card.types.ts`.

## Тема

Тёмная тема работает механизмом набора: хост ставит `data-a2ui-theme="dark"` (или `color-scheme`) на
предке, токены `light-dark()` читают его. Проверено в headless Chrome, скриншоты `*-dark.png`.
Своих цветов у компонента нет.
