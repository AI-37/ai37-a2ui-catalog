## ADDED Requirements

### Requirement: Кнопка с файлом недоступна без загруженного файла

Карточка SHALL держать кнопку `attach` неактивной, пока выбранный файл не загружен на полку треда и не получен `fileId`; кнопка `skip` SHALL быть активной до отправки и во время загрузки — неактивной.

#### Scenario: Файл не выбран

- **WHEN** карточка только отрисована
- **THEN** `attach` неактивна, `skip` активна

#### Scenario: Файл загружается

- **WHEN** пользователь выбрал файл и ответ ручки ещё не пришёл
- **THEN** обе кнопки неактивны, виден статус загрузки с именем файла

### Requirement: Загрузка файла на полку треда

Рендерер SHALL загружать выбранный файл same-origin multipart POST на `CHAT_ATTACHMENTS_ROUTE` с полями `file` и `contextId` из props, а сбой ответа SHALL показывать ошибкой с возможностью выбрать файл заново.

#### Scenario: Успешная загрузка

- **WHEN** ручка ответила `{fileId}`
- **THEN** рядом с кнопкой виден чип с именем и размером, `attach` активна

#### Scenario: Сбой загрузки

- **WHEN** ручка ответила не-2xx
- **THEN** виден текст ошибки с `role="alert"`, `attach` неактивна, выбор файла снова доступен

### Requirement: Контракт действия

Обе кнопки SHALL диспатчить действие с именем `action` из props: `skip` — контекст `{value: skip.value}`, `attach` — `{value: attach.value, fileId, fileName}`; после отправки обе кнопки SHALL быть неактивны.

#### Scenario: Без файла

- **WHEN** пользователь нажал `skip`
- **THEN** уходит одно действие с `{value}` без `fileId`

#### Scenario: С файлом

- **WHEN** файл загружен и пользователь нажал `attach`
- **THEN** уходит одно действие с `{value, fileId, fileName}`
