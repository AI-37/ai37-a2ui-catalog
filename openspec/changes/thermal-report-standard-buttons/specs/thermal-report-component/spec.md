## MODIFIED Requirements

### Requirement: Протокол свёрнут по умолчанию

Секция `protocol` SHALL рендериться одной неразворачиваемой строкой: лейбл
«Протокол расчёта», сводка (`meta`) и — при заданном `downloadFileName` —
ссылка-кнопка «Скачать». Элементов раскрытия (нативный `<details>`, шеврон)
SHALL NOT быть; `content` в UI не показывается. «Скачать» SHALL отдавать
клиентским Blob'ом `downloadContent` (полную простыню; без него — `content`)
под именем `downloadFileName`; без `downloadFileName` кнопки нет.

#### Scenario: Протокол — одна строка

- **WHEN** рендерится отчёт с секцией `protocol`
- **THEN** видна одна строка с лейблом, `meta` и «Скачать»; `content` не
  отображается, и кликом по строке ничего не раскрывается

#### Scenario: Скачивание протокола

- **WHEN** пользователь нажимает «Скачать» при заданных `downloadFileName` и
  `downloadContent`
- **THEN** браузер сохраняет `downloadContent` (полную простыню) файлом с
  этим именем

## ADDED Requirements

### Requirement: Кнопки отчёта соответствуют канону CE

Кнопки термо-отчёта («Подобрать», «Изменить и пересчитать», «Вернуть в
расчёт», «Скачать») SHALL визуально соответствовать стандартным кнопкам
других форм каталога (канон `a2ui-ce-btn` / `a2ui-ce-link`): solid — как
`--commit`, link — как `a2ui-ce-link`; «Изменить и пересчитать» — link, как
«Скачать».
Стили SHALL включать собственные hover/фокус-переопределения с
специфичностью, перебивающей хостовые правила (`.a2ui-surface button:hover`
и т.п.), чтобы хост не перекрашивал кнопки серой пилюлей и не добавлял
обводку-капсулу ссылкам.

#### Scenario: Ссылка без хостовой капсулы

- **WHEN** «Скачать» / «Изменить и пересчитать» / «Вернуть в расчёт»
  рендерятся внутри хостового чата
- **THEN** они выглядят как текстовые ссылки акцентного цвета с
  подчёркиванием на ховере, без рамки и заливки
