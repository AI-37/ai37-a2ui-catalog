## Why

В хосте (sp-ai chat) кнопки термо-отчёта выглядят не как стандартные кнопки других форм каталога (constructions-editor / lift-editor): «Изменить и пересчитать» рендерится серой хостовой пилюлей, «Скачать» — с хостовой обводкой-капсулой. Причина: `.a2ui-tr` не переопределяет хостовые hover/фокус-стили (`.a2ui-surface button:hover` и т.п.), как это делает канон CE. Кроме того, «Протокол расчёта» пользователю нужен просто строкой (лейбл + «Скачать»), без возможности разворачивать содержимое.

## What Changes

- Кнопки термо-отчёта («Подобрать», «Изменить и пересчитать», «Вернуть в расчёт», «Скачать») приводятся к канону CE-кнопок: те же метрики/варианты, что `a2ui-ce-btn` / `a2ui-ce-link`, включая собственные hover-переопределения, гасящие хостовые стили (серую пилюлю/обводку).
- **BREAKING (UI)**: блок «Протокол расчёта» перестаёт быть разворачиваемым `<details>` — остаётся одна строка: лейбл «Протокол расчёта», meta и ссылка «Скачать». Текстовое содержимое `content` в UI больше не показывается; скачивание (`downloadContent ?? content`) сохраняется.

(нет)

### Modified Capabilities

- `thermal-report-component`:
  - Requirement «Протокол свёрнут по умолчанию» заменяется: протокол — неразворачиваемая одиночная строка (лейбл + meta + «Скачать»), сценарий раскрытия удаляется, сценарий скачивания сохраняется.
  - Добавляется requirement о визуальном каноне кнопок: кнопки отчёта соответствуют стандарту CE-кнопок и не перекрашиваются хостовыми hover/фокус-стилями.

## Impact

- `packages/catalog-react/src/renderers/thermal-report-protocol.tsx` — убрать `<details>/<summary>`, оставить строку лейбл + «Скачать».
- `packages/catalog-react/src/renderers/thermal-report-styles.ts` — hover-переопределения против хоста (по образцу `constructions-editor-styles.ts`), стили строки протокола.
- `packages/catalog-react/src/renderers/thermal-report-action-button.tsx` — классы/варианты без изменений API; поведение диспатча не меняется.
- Схема `@ai37/a2ui-catalog-schemas` (`thermal-report.ts`) не меняется: поля `protocol.content/downloadContent/downloadFileName` остаются, меняется только их отображение.
- Тесты: `tests/react/thermal-report.test.tsx` — сценарий раскрытия протокола удалить/переписать.
