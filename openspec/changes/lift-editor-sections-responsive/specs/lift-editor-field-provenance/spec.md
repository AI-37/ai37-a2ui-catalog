## ADDED Requirements

### Requirement: Источники значений полей приходят параллельным блоком

Схема `LiftEditor` SHALL принимать опциональные `buildingSources` — объект
по именам полей здания — и `liftSources` — массив таких объектов по индексам
лифтов. Каждый элемент — `{source, note?}`, где `source` — одно из
`project` | `question` | `suggested` | `default`, а `note` — необязательное
обоснование одной строкой (≤200 символов). Источники SHALL NOT смешиваться со
значениями: `building` и `lifts` остаются прежними.

#### Scenario: Пропы опциональны

- **WHEN** агент прислал props без `buildingSources` и `liftSources`
- **THEN** props проходят валидацию, компонент рисует поля без подписей
  источника

#### Scenario: Неизвестный источник отвергается

- **WHEN** в `buildingSources` передан `source: 'guessed'`
- **THEN** валидация схемы завершается ошибкой

### Requirement: Подпись поля по источнику

Для поля с заданным источником компонент SHALL показывать подпись под
контролом: `note`, а при её отсутствии — словоформу источника («из проекта» /
«из вопроса» / «предложено агентом» / «принято по умолчанию»). Оформление
самого контрола SHALL NOT зависеть от источника — все поля выглядят
одинаково, различаются только подписи (у `suggested`/`question` подпись может
быть акцентного цвета). Provenance SHALL быть только отображением: оно SHALL
NOT блокировать ввод или submit.

#### Scenario: Подпись-обоснование

- **WHEN** `buildingSources.A` = `{source: 'question'}` с note «из вашего
  вопроса»
- **THEN** под полем `A` показана эта подпись

#### Scenario: Словоформа без note

- **WHEN** `liftSources[0].Q` = `{source: 'suggested'}` без note
- **THEN** под полем `Q` первого лифта показано «предложено агентом»

### Requirement: Правка поля снимает provenance

Изменение значения поля пользователем SHALL снимать подпись источника этого
поля независимо от введённого значения. Новый снапшот props SHALL
восстанавливать provenance по присланным блокам.

#### Scenario: Ввод делает значение пользовательским

- **WHEN** пользователь правит поле с подписью «предложено агентом» и
  возвращает прежнее значение
- **THEN** подпись источника у поля отсутствует

#### Scenario: Снапшот агента возвращает подписи

- **WHEN** после правок приходит новый снапшот props с `buildingSources`
- **THEN** подписи источников отрисованы по новому снапшоту

### Requirement: Provenance не попадает в payload

Контексты submit'а и черновика SHALL остаться `{method, building, lifts}`.
Источники значений SHALL NOT включаться в отправляемый контекст.

#### Scenario: Payload не меняется

- **WHEN** пользователь отправляет форму, пришедшую с `buildingSources` и
  `liftSources`
- **THEN** контекст action'а не содержит ключей источников
