## ADDED Requirements

### Requirement: Стили пакета вместо инлайновых

Рендереры `LiftEditor` SHALL использовать классы с префиксом `a2ui-le-` и
CSS-слой, инжектируемый компонентом (общий механизм `<style href precedence>`
пакета). Инлайновые стили разметки SHALL быть удалены. Цвета SHALL браться
только из токенов `var(--a2ui-*)`; потребитель SHALL NOT быть обязан
импортировать CSS-файл.

#### Scenario: Один тег стилей на много редакторов

- **WHEN** в треде отрисованы два `LiftEditor`
- **THEN** в документе один тег стилей `LiftEditor` (дедупликация по `href`)

#### Scenario: Тема хоста применяется

- **WHEN** хост переопределяет токены `--a2ui-*` для тёмной темы
- **THEN** редактор рисуется в цветах хоста без переопределения классов
  `a2ui-le-*`

### Requirement: Брейкпоинты по ширине контейнера

Корень компонента SHALL получить `container-type: inline-size` и ширину
100 % контейнера (`min-width: 0`). Сетки полей секций SHALL быть одной
колонкой в базе и двумя колонками от брейкпоинта ~560px по **ширине
контейнера** (`@container`), не окна. Фиксированная колонка
`FIELD_COLUMN_WIDTH` SHALL NOT применяться в `LiftEditor`.

#### Scenario: Широкий контейнер — две колонки

- **WHEN** контейнер редактора шире брейкпоинта
- **THEN** поля секции здания раскладываются в две колонки на всю ширину
  контейнера

#### Scenario: Узкий контейнер — одна колонка

- **WHEN** контейнер уже брейкпоинта (например, мобильная ширина 390)
- **THEN** все поля идут одной колонкой, горизонтального скролла нет

#### Scenario: Хост без поддержки container queries

- **WHEN** браузер не поддерживает `@container`
- **THEN** редактор остаётся в одноколоночной базовой раскладке и полностью
  функционален
