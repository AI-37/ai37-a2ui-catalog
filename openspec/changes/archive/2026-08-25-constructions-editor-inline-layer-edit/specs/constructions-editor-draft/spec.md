## MODIFIED Requirements

### Requirement: Автосохранение на структурных правках

При заданном `draftAction` компонент SHALL отправлять
`dispatchAction({event: {name: draftAction, context: {…}}})` после каждого
**коммита** состояния конструкций: добавления конструкции, удаления
конструкции, коммита формы слоя «Добавить», удаления слоя, а также коммита
«Применить», изменившего слой. «Применить» без изменений SHALL NOT порождать
action. Контекст SHALL содержать полный текущий массив `constructions` (при
наличии `general` — и его) в том же формате, в каком он уходит в
`submitAction`, включая незаполненные и невалидные записи. Определение
коммита SHALL быть явным событием, а не выводиться из сравнения длин
массивов.

#### Scenario: Добавлена конструкция

- **WHEN** пользователь нажимает кнопку добавления конструкции
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` присутствует новая пустая конструкция
  вместе со всеми ранее введёнными

#### Scenario: Удалена конструкция

- **WHEN** пользователь удаляет карточку конструкции
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** удалённой конструкции нет в `context.constructions`

#### Scenario: Добавлен или удалён слой

- **WHEN** пользователь коммитит форму нового слоя «Добавить» либо удаляет
  слой из формы
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` эта конструкция содержит актуальный набор
  слоёв

#### Scenario: Применить с изменёнными полями слоя

- **WHEN** пользователь вписывает λ в форме слоя и нажимает «Применить»
- **THEN** компонент отправляет один action с именем `draftAction`
- **AND** в `context.constructions` слой содержит введённую λ

#### Scenario: Применить без изменений

- **WHEN** пользователь открывает форму слоя и сразу нажимает «Применить»
- **THEN** компонент не отправляет ни одного action'а

#### Scenario: Незаполненные данные не мешают

- **WHEN** коммит происходит при незаполненных обязательных полях
- **THEN** компонент всё равно отправляет `draftAction`
- **AND** клиентская валидация не запускается и submit не блокируется

### Requirement: Правки полей не запускают автосохранение

Компонент SHALL NOT отправлять `draftAction` в ответ на изменение полей вне
формы слоя — типа конструкции, subtype, названия, паспортного Rпр, полей
вкладки общих данных — а также на ввод внутри ещё не закоммиченной формы
слоя, на «Отмену» формы и на разворачивание/сворачивание карточек и строк.
Такие правки SHALL уезжать наружу вместе со следующим коммитом либо с
`submitAction`.

#### Scenario: Правка шапки без коммита

- **WHEN** пользователь меняет название конструкции
- **THEN** компонент не отправляет ни одного action'а

#### Scenario: Ввод в форме слоя без коммита

- **WHEN** пользователь печатает в полях открытой формы слоя, не нажимая
  «Применить»
- **THEN** компонент не отправляет ни одного action'а

#### Scenario: Правка шапки перед коммитом

- **WHEN** пользователь меняет название конструкции, а затем добавляет
  вторую конструкцию
- **THEN** отправляется ровно один action `draftAction`
- **AND** в `context.constructions` первая конструкция содержит новое
  название
