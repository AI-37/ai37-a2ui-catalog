## Why

Сейчас чип Rпр в шапке карточки конструкции пересчитывается только после
«Применить»: черновик формы слоя живёт в локальном state `LayerForm` и наверх
не поднимается. Пользователь, подбирающий толщину или λ утеплителя, не видит
эффекта правки, пока не закоммитит форму — цикл «поменял → применил →
посмотрел → снова открыл форму» ломает основной сценарий подбора слоя под
норму.

## What Changes

- Чип Rпр карточки пересчитывается мгновенно по мере правок в открытой форме
  слоя (толщина, λ ручная, материал из справочника с авто-λ) — до нажатия
  «Применить».
- То же для формы нового слоя («+ Слой»): ещё не добавленный слой уже
  участвует в превью Rпр.
- То же для формы паспортного Rпр типов без слоёв.
- Всё остальное поведение коммита не меняется: состояние редактора,
  строки-сводки, статусные чипы, подсветка невалидности, сводка «проходит N из
  M» и черновики агенту (`draftAction`) по-прежнему обновляются только по
  «Применить»/«Добавить»; «Отмена» и переключение формы возвращают чипу
  закоммиченное значение.

## Capabilities

### New Capabilities

- `constructions-editor-rpr-preview`: live-превью Rпр в чипе карточки из
  черновика открытой формы (слой edit/new, паспортное Rпр) — область действия,
  сброс при отмене/переключении формы, невлияние на state и черновики.

### Modified Capabilities

- `constructions-editor-inline-layers`: требование «Правки слоя попадают в
  state по «Применить»» уточняется — live-Rпр исключается из инварианта
  «ничего не меняется до коммита» (сценарий «Ввод в форме не трогает live-Rпр»
  заменяется на обратный для чипа Rпр, при неизменности state/сводок/черновиков).

## Impact

- `packages/catalog-react/src/renderers/constructions-editor-layer-row.tsx` —
  форма слоя сообщает черновик наверх по мере правок.
- `packages/catalog-react/src/renderers/constructions-editor-passport.tsx` —
  то же для формы паспортного Rпр.
- `packages/catalog-react/src/renderers/constructions-editor-card.tsx` —
  карточка держит превью-черновик и считает `computeLiveRpr` по подменённому
  слою/паспорту для чипа.
- `tests/react/constructions-editor.test.tsx` — существующий тест
  «ввод в форме не трогает live-Rпр» переворачивается; новые тесты на превью.
- Схема props (`catalog-schemas`) не меняется, action'ов не добавляется;
  серверный канонический расчёт не затрагивается.
