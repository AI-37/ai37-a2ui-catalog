## ADDED Requirements

### Requirement: Чип Rпр видит черновик открытой формы

Чип Rпр карточки SHALL пересчитываться мгновенно по мере правок в открытой
форме, влияющей на Rпр: форме существующего слоя, форме нового слоя
(«+ Слой») и форме паспортного Rпр типов без слоёв. Для формы существующего
слоя превью SHALL считаться по составу с подменённым редактируемым слоем; для
формы нового — по составу с черновиком, добавленным в конец; для паспортной —
по черновому значению `rprPassport`. Сравнение с Rнорм и цвет чипа SHALL
следовать превью-значению по прежним правилам.

#### Scenario: Толщина меняет чип без «Применить»

- **WHEN** пользователь меняет толщину в открытой форме слоя, не нажимая
  «Применить»
- **THEN** чип Rпр карточки показывает пересчитанное значение
- **AND** цвет и знак сравнения с Rнорм соответствуют новому значению

#### Scenario: Ручная λ и материал из справочника тоже live

- **WHEN** пользователь вписывает ручную λ или выбирает материал с авто-λ из
  справочника в открытой форме слоя
- **THEN** чип Rпр пересчитан с учётом новой λ до коммита формы

#### Scenario: Черновик нового слоя участвует в превью

- **WHEN** пользователь в форме «+ Слой» заполнил материал, толщину и λ, не
  нажимая «Добавить»
- **THEN** чип Rпр показывает сумму с учётом ещё не добавленного слоя

#### Scenario: Паспортное Rпр — live

- **WHEN** пользователь правит значение в открытой форме паспортного Rпр
- **THEN** чип Rпр показывает вводимое значение до «Применить»

### Requirement: Превью не переживает форму и не трогает state

Превью SHALL действовать только пока форма-источник открыта: «Отмена»,
переключение на другую форму или закрытие карточки SHALL возвращать чип к
значению из закоммиченного состояния; коммит SHALL делать превью и
закоммиченное значение неразличимыми (без скачка чипа). Открытие формы без
правок SHALL NOT менять чип. Превью SHALL NOT изменять состояние редактора,
строки-сводки, статусные чипы, подсветку невалидности, сводку «проходит N из
M» и SHALL NOT порождать action'ов или черновиков (`draftAction`).

#### Scenario: Отмена возвращает чип

- **WHEN** пользователь изменил толщину в форме слоя и нажал «Отмена»
- **THEN** чип Rпр показывает прежнее закоммиченное значение

#### Scenario: Переключение формы сбрасывает превью

- **WHEN** при открытой форме второго слоя с правками пользователь кликает по
  четвёртому слою
- **THEN** чип Rпр считается из закоммиченного состава: правки второго слоя в
  превью не участвуют

#### Scenario: Неполный черновик выпадает из суммы

- **WHEN** пользователь стёр толщину слоя в открытой форме
- **THEN** чип Rпр показывает сумму без этого слоя — как для незаполненной
  строки, без ошибок и NaN

#### Scenario: Черновиков от ввода не появляется

- **WHEN** пользователь правит поля открытой формы слоя при заданном
  `draftAction`
- **THEN** до «Применить» никакие action'ы не диспатчатся
