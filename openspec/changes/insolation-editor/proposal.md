# InsolationEditor: сбор исходных данных расчёта инсоляции

## Why

Расчёт продолжительности инсоляции (СанПиН 1.2.3685-21, методика
ГОСТ Р 57795) — смежный с КЕО модуль SP AI: те же данные проекта (регион,
этажи, окна, застройка), тот же паттерн диалогового сбора. Согласован макет
формы «Параметры расчёта»; компонента в каталоге нет, а плоские FormCard
фрагментируют чат.

## What Changes

- **Новый компонент каталога `InsolationEditor`** (аддитивно, v2): условия
  (readonly регион с широтной зоной + норматив), повторяемые **расчётные
  точки** («+ Добавить расчётную точку») и повторяемая **затеняющая
  застройка** («+ Добавить здание») — локальным state'ом; один submit
  «Рассчитать» с полным документом.
- **Расчётная точка**: этаж, ориентация окон (румб + азимут), отметка
  центра окна (рассчитана агентом по этажу, редактируемая), дата проверки
  (рассчитана — худший день нормируемого периода, редактируемая).
- **Затеняющее здание** — строка: направление от окна, расстояние, высота,
  фронт; warning-плашка об упрощённой модели («прямоугольные экраны»,
  не указанная застройка завышает результат) — строки из props.
- **Метки источника** (из проекта / из вопроса / рассчитано / предложено /
  допущение) и счётчик в футере — канон CE/LE.
- **Нормативных данных на клиенте нет**: широтная зона, норматив часов,
  нормируемый период и худший день приходят готовыми строками от агента.
  ⚠ В макете для центральной зоны показан период «22 апреля — 22 августа» —
  требует сверки с текстом СанПиН 1.2.3685-21 на агентской стороне
  (reference-выписок по инсоляции в проекте нет; по предварительным данным
  этот период относится к северной зоне, а у центральной период шире и
  худший день иной). Контракт компонента от исхода сверки не зависит.
- Фикстуры, превью в apps/demo, TS/React/Python-тесты.

## Capabilities

### New Capabilities

- `insolation-editor`: контракт компонента — схема props, повторяемые
  расчётные точки и здания застройки на клиенте, вычисленные агентом
  редактируемые значения с метками источника, warning-плашки модели,
  один submit с полным документом.

### Modified Capabilities

_(нет)_

## Impact

- `packages/catalog-schemas`: `components/insolation-editor.ts` +
  регистрация; export:public.
- `packages/catalog-react`: `renderers/insolation-editor*.tsx/.ts`
  (паттерн LiftEditor), группа токенов `ie`, регистрация.
- `packages/catalog-python`: зеркальная модель + parity-тест.
- `fixtures/*`, `apps/demo`, `tests/react`; version bump + CHANGELOG.
- Потребители: будущий агент инсоляции SP AI (расчётного ядра ещё нет —
  компонент делается по согласованным макетам впрок), spai-ui bump.
- **Non-goals**: расчёт солнечной геометрии и нормативов на клиенте;
  подоснова/генплан файлом (в макете помечено «в разработке» — отдельный
  change); 3D-модель застройки; проверка «по квартире» (уровень проекта —
  действие в отчёте, не в редакторе).
